## Source checks

- Frame ownership: active movement requests coalesce into display frames, while idle/stalled requests render immediately (mm:1620-1630). The macOS 14+ driver uses a view display link and per-screen maximum frame rate; the fallback timer uses a weak overlay reference (mm:1632-1657). Resting motion pauses the driver; hide/cancellation stop it; native-controls invalidation invalidates and releases the display link (mm:1660-1712, 2530-2542). The C++ owner invokes invalidation on destruction. Unchanged rounded frames are skipped and same-size movement uses `setFrameOrigin` (mm:1943-1960). These establish implementation properties, not measured speed or power improvements.
- Pinch ownership: pinch stops the old driver, takes a gesture snapshot, synchronously applies each native frame, and preserves the model across live preference updates. Completion/cancellation resolves the snapshot before decoration is reconstructed; hide/block/reconfiguration cancellation also restores it before model release (mm:1691-1712, 2235-2270). No new global application activation was introduced.
- Explicit tuck shading: button tuck now seeds a tucked model and requests a frame when Edge shading is enabled (mm:2036-2055). `ensureMotionLayers` creates the internal gradient, and the tucked state contributes a persistent edge target (mm:1602-1616, 1815-1832, 1900-1919). Restore and effect-disable paths remove it. The control test checks the explicit-button shade and plain handle host.
- Glass/layout/input: responsive scaling uses bounded sizes; seek buttons disappear at compact dimensions; hit testing converts into the actual control bounds and rejects hidden/transparent surfaces (mm:1274-1340). Glass tint is subtle on macOS 26, with material and opaque Reduce Transparency fallbacks (mm:88-120, 147-167). The tucked handle is a plain host with a chevron, above internal edge shading.

The native controller observes live changes through a weak callback. Haptics and Return remain separately gated; default-off visual effects remove companions and restore the original native shadow.
