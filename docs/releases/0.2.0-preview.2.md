# Arcium 0.2.0-preview.2

UNRELEASED. These are draft notes for a local candidate. The published download
remains `0.2.0-preview.1`. Native candidate checks covered import, selected-Space
refresh, cached icons, and normal restart in isolated profiles. Release
verification is recorded separately.

## Highlights

- Start with Arc. The first screen can import all eligible saved Spaces, Pins,
  folders, and Favorites in one click. History stays off.
- Choose specific Spaces. Pick individual Spaces or Select all. Arcium keeps
  attached Arc profiles separate without asking you to map browser folders.
- Start browsing after import without granting service consent. Configure is
  optional. Settings can reopen the Space picker later.

## Polish and fixes

- New import profiles inherit the welcome profile's layout and material settings.
  Existing destinations keep their settings on retry or refresh.
- Import progress and per-Space results stay in the page. Retry failed work
  without repeating completed imports.
- Keep warnings visible when some Arc data is unavailable, even after the
  available Spaces import successfully. A clean reread clears the warning.
- Recover from an imported Space that fails to open. Retry opening it or finish
  setup without opening it.
- Show setup controls without waiting for the introduction, and stop the
  background animation after it finishes.

## Import limits

Passwords, cookies, extensions, and existing sign-ins do not move through this
flow. History is optional in the custom picker and starts off for each request.
Repeated History imports can add duplicate visits.

Refreshing a selected Space replaces its imported saved tree, including edits
inside that tree. Unselected Spaces and independently maintained local records
stay in place. Stopping an import does not undo data that already arrived.

Arc split views become individual saved pages. Little Arc's temporary windows
and foreign-machine profile records are excluded. A successful import covers the
available selected data, not a guarantee that every Arc record was available.

See [Import from Arc](../import-from-arc.md) for the source flow, the older dialog
in preview.1, and separate password migration. Exact build, signing, notarization,
and native acceptance results belong in the candidate's verification record.
