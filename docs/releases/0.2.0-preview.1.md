# Arcium 0.1.0 (Preview) — RIP Arc

October 23, 2026

**Helium's privacy and speed, with Arc polish.** The sidebar workflow we love, in a browser we can keep building.

**[Download for Mac](https://github.com/dr-baker/Arcium-macOS/releases/download/0.2.0-preview.1/Arcium-0.2.0-preview.1-macOS-arm64.dmg)** · Apple Silicon · macOS 26+

## In this release

- **Spaces, Pins, and Favorites.** Organize saved pages and folders in a familiar sidebar. Experimental split Pins keep two pages together.
- **An omnibox with more.** Search tabs, saved pages, and the web from one glass command bar. Jump into YouTube or X search, or start a fresh ChatGPT conversation.
- **Make it yours.** Space colors, glass, grain, sidebar layouts, and native macOS Settings. New profiles start with pastel colors and a hidden address bar.
- **Stay in context.** Recent-tab previews with Control-Tab, Peek for links, and Little Arc for links from other apps.
- **Bring your Arc sidebar.** Import Spaces, Pins, folders, Favorites, and optional History through the import dialog. Favorites-only profiles get a visible home too.
- **Finishing touches.** A pink app icon, aligned traffic lights, soft command-bar glows, and typed searches kept as the default action.

## Get started

Open the DMG, open **Install Arcium**, and click **Install**. Press **Command-L** to enter an address and **Command-Comma** for Settings. [Quickstart](https://github.com/dr-baker/Arcium-macOS/blob/main/docs/arc-quickstart.md) · [Import from Arc](https://github.com/dr-baker/Arcium-macOS/blob/main/docs/import-from-arc.md#advanced-import)

Updating an existing installation? Quit Arcium and move the old app to the Trash first. The installer preserves browsing data and settings.

## Preview limits

Chromium **151.0.7922.71** is not a current Chromium security release. Browser updates are manual. Passwords and sign-ins need separate migration; repeating History imports can duplicate visits. Arc split layouts are not preserved during import.

One-click welcome migration and original Space icons are coming in the next release; they are not in this download. [Full limits](https://github.com/dr-baker/Arcium-macOS/blob/main/docs/preview-release.md#limits) · [What's next](https://github.com/dr-baker/Arcium-macOS/blob/main/CHANGELOG.md)
